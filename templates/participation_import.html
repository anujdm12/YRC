What the importer does
  • Matches by register number first, then by exact full name only when it uniquely identifies one roster student. Uses the latest response per register number.
  • Combines “Ethnic Day” and “Ethnic Day Volunteer”.
  • Skips “None”, preserves records already marked Present, and flags unmatched or duplicate-name records.
  • Asks for an event date when it needs to create a new event; form timestamps are not event dates.
BEFORE YOU IMPORT

Keep the roster in sync

Each activity row is matched by register number, with a unique exact full-name fallback. Duplicate-name and unmatched entries are listed in the preview for review.

Each confirmed activity is saved as a selected participant with Present attendance.

Reuploading the same sheet is safe: existing Present records won’t be duplicated.
